# 0.2.29

## 本版修复

- 修复鼠标穿透的透明覆盖层干扰窗口吸附，保留普通窗口和半透明交互窗口的选取。
- 修复系统剪贴板逻辑为空、仅有 OLE 内部标记时的划词读取与恢复。

## 自上次公开版 0.2.21 以来

- 滚动长截图支持上下及往返滚动，显示范围边框、实时缩略预览和累计尺寸，支持 F9 手动补帧及 F8 完成。
- GIF 录制提供省空间、均衡、清晰、原尺寸四档画质，合并重复帧并按变化区域流式编码。
- 截图支持窗口吸附、显示器全屏、F1 操作提示、F2 指针切换及可配置的选区边框宽度。
- 改善大图标注局部重绘、临时位图释放、历史异步解码与刷新时的选中项保持。
- 长截图按最终尺寸控制容量，上限为 24000 像素高、5000 万像素。
- 完善 Ark 多模型并行翻译、百度翻译段落空行处理、表格工作簿覆盖保存及文本断行合并。

安装、快捷键和功能边界见 [使用指南](USAGE.md)，回归范围见 [验证记录](VALIDATION.md)。
