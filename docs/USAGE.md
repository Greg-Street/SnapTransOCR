# 使用指南 · 0.2.21

解压运行程序，右键托盘打开设置。Alt+1 截图与标注，Ctrl+Shift+A 划词翻译，Ctrl+Shift+S 打开历史。快捷键可以自定义，冲突时请在设置中调整。

## 截图与图片

截图支持矩形、椭圆、线条、箭头、画笔、文字、马赛克、裁剪、撤销和重做。保存默认 PNG。图片可以贴在桌面、缩放、选择文字，并在原图和译图之间切换。

## OCR 与翻译

在设置中启用所需服务并填写自己的凭据。关闭服务不会删除已保存的配置；全部关闭时仍可截图、标注和贴图。识别和翻译会把所选内容发送到启用的服务。接口权限、网络、配额与费用由服务商决定，详见 [服务说明](SERVICES.md)。

## 历史与剪贴板

可记录文字、图片、OCR 和翻译结果，支持搜索、筛选、复制、暂停和删除。保存期限为 1–3650 天，默认 7 天，保存设置后生效。历史优先保存于程序目录 `data/history`，不可写时回退并在界面显示实际位置。

配置保存于当前用户的 LocalAppData 目录。配置中可能包含明文服务凭据，历史中可能包含敏感文字和图片；不要把配置、历史或浏览器个人资料加入公开反馈。

## 安装与更新

可直接运行便携包，也可运行 `install.ps1` 安装到当前用户的 Programs 目录；使用 `-Destination` 可以指定专用目录。更新前先从托盘退出，保留自己的数据目录。运行脚本前可查看其内容。

## 限制

复杂表格、斜排文字、混合字体、长译文与混合 DPI 多屏仍需人工核对。必应在线接口可能变化或限流。验证范围见 [VALIDATION.md](VALIDATION.md)。
