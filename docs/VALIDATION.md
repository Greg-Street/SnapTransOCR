# 0.2.29 验证范围

开发版在 2026-11-12 完成 C# 7.3、.NET Framework 4.8、x64 优化编译，警告作为错误。原始验证记录显示完整无界面回归通过 2740 项断言，完整原生回归通过 2813 项断言。

原生专项覆盖窗口候选筛选、透明覆盖层、空剪贴板恢复、滚动方向、截图交互、历史、GIF 和设置布局。专项存在交叉覆盖，数量不能与完整回归相加。云接口使用模拟请求与响应。

本次公开发布重新构建公开源码，无界面回归通过 2740 项断言。生成的程序与已验证开发版的 SHA-256 一致。源码包、发行附件、说明链接和隐私经过检查，公开截图使用独立演示数据生成。

原生回归结果引用开发版已有记录。云端服务质量、账户权限和配额需按使用者自己的配置核对。滚动拼接依赖画面重叠，动画、重复图案、复杂浮层及混合 DPI 多屏仍需人工核对。
