## 可重复运行的检查

在满足 README 构建依赖的 Windows 环境中：

```powershell
.\build.ps1 -Test -Headless
.\dist\SnapTransOCR.Tests.exe --history-clipboard-only
```

完整回归中，模拟 DPI 滚动测试在旧版 0.2.18 与后续版本均观察到失败。历史专项通过不代表该问题已经解决，也不代表所有混合 DPI、多屏、显卡或第三方剪贴板组合均已验证。

本仓库保留源码、测试和必要文档；个人运行历史、API 凭据、原始诊断截图和开发日志未随仓库发布。测试结果属于已有版本记录，不是对所有云服务或硬件环境的保证。
